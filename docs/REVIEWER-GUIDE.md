# Reviewer guide

[Open prototype](https://fistulavoice.vercel.app/) · [README](../README.md)

## What to evaluate

The MVP demonstrates a consistent, replayable fistula sound history. Evaluate its workflow, comparability rules and documentation. It is not a diagnostic-performance demonstration.

## Without microphone access

1. Open **History → Demo timeline**.
2. Choose Site 1 and different dates. Inspect changes from the first/previous visit.
3. Choose Site 2 to see its separate history. All timeline values are fictional.
4. Open **Signals** and play a recording. Try pause, seek and Freeze waveform.
5. Review the source-supplied case labels. These are different participants, not a progression sequence.
6. Open **Evidence** for the studies, limitations and validation priorities.

## Optional recording test

1. Open **Record** and use a non-medical test sound.
2. Enter `DEMO-ACCESS-A`, device `PHONE-A`, Site 1 and a condition.
3. Start recording and grant microphone access. Stop manually or wait for the 20-second limit.
4. Repeat using the same metadata.
5. Open **History → My recordings**. Expand **Listen across visits** on the later recording to hear the previous compatible sample.
6. Save a review note. Refresh to verify browser-local persistence.
7. Use **Library** for measurements, audio downloads and deletion; export measurements as needed.

Different decoded sample rates or metadata prevent pairing. This is intentional. Matching metadata does not guarantee identical physical placement or medically reliable capture.

## Before submitting

- Confirm reviewers can access GitHub; a private repository requires explicit access.
- Open the demo in a private/incognito window.
- The submitted screenshot requests a completed filtering/prototype form, accepting PDF, Word, PowerPoint, PNG or JPG up to 50 MB.
- It also indicates the organizer's template has not yet been published. Follow the organizer's template requirement; do not assume the presentation replaces it. Obtain their direction if it remains unavailable before the deadline.
- Microphone access is optional for the timeline and research-audio demonstration.
